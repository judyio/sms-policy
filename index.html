SMS Program — Personal AI Assistant

This page describes the text-messaging program for the personal AI assistant operated by Clinton Judy (sole proprietor).

How to opt in:

Text START to +1 (708) 773-5363 to opt in to the assistant's SMS program.

By texting START to +1 (708) 773-5363, you agree to receive text messages (conversational replies, reminders, and notifications you request) from this personal assistant service. Access requires pre-authorization by the account holder — the assistant only converses with numbers he has personally approved.

Message frequency varies. Message and data rates may apply. Reply HELP for help, STOP to cancel at any time.

What this program is

A private, personal-use assistant line for the account holder and a small set of individuals he has personally pre-authorized (family and close contacts). It sends no marketing, promotional, or bulk messages. Consent is never a condition of any purchase, and mobile numbers are never shared with or sold to third parties.
